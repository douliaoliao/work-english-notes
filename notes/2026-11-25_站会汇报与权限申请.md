## 站会追问练习

**Q: Does this issue affect QA testing or deployment?**

这个问题会影响 QA 测试或发布吗？

**A: I confirmed that it doesn't affect QA testing or deployment.**

我已确认它不会影响 QA 测试或发布。

**Q: When will you update the team?**

你什么时候向团队同步进展？

**A: Once the support team replies, I'll update the team in Teams.**

支持团队回复后，我会在 Teams 中向团队同步进展。

**补充句型（课堂练习，尚未确认是实际安排）：**

如果到明天站会仍然没有回复，我会在会上再提一下。

## 重点词汇

| 词语 | 含义 | 本次场景中的用法 |
| --- | --- | --- |
| locally | 在本地；副词 | debug locally：在自己的电脑或本地开发环境中调试 |
| grant / grants | 授予、批准给予 | The support team grants me access：支持团队授予我权限；本句把 team 作为单数整体，使用 grants |
| promptly | 及时地、迅速地 | update the team promptly：及时向团队同步进展 |
| properly | 正确地、妥当地 | The service isn't working properly：服务运行不正常；它不表示“及时” |
| confirm / confirmed | 确认 | I confirmed that it doesn't affect testing：我已确认它不影响测试 |
| concern | 涉及、使担忧；也可作名词表示担忧 | 本次要表达“确认”，应使用 confirm |
| expected behavior | 符合预期的行为 | It was expected behavior, so no fix was needed. |
| request access | 申请访问权限 | I submitted a ticket to request Key Vault access. |

## 本次重点纠正

| 原表达或易错点 | 推荐表达 | 原因 |
| --- | --- | --- |
| tomorrow I fix…（描述昨天） | Yesterday, I worked on fixing… | 时间应是 yesterday，已发生的动作使用过去式 |
| Also had a one-one meeting… | I also had a one-on-one meeting… | 补主语 I；固定表达是 one-on-one |
| it didn't bug | It wasn't a bug. / It was expected behavior. | bug 是名词；这里用 be 动词 |
| I check it and confirm…（描述已完成的检查） | I checked it and confirmed… | 过去完成的动作使用过去式 |
| no fix was need | no fix was needed | 被动结构使用过去分词 needed |
| I submit / summit a ticket | I submitted a ticket. | submit 是提交，过去式为 submitted；summit 是另一个词 |
| keyboard access | Key Vault access | 这里指 Key Vault 权限；语音转写可能把专有名词识别错 |
| Once support granted access, I will… | Once support grants access, I'll… | once 引导将来的时间条件时，从句通常使用一般现在时；这里是 grants，不是 granted |
| update the team properly（想表达及时） | update the team promptly | promptly 表示及时，properly 表示妥当 |
| if there are no reply | if there's no reply | 单数 reply 搭配 there is；也可说 if there are no replies |
| it's not affect… | it doesn't affect… | 一般现在时否定使用 doesn't + 动词原形 |
| I concern…（想表达我确认） | I confirmed that… | confirm 才表示确认 |
